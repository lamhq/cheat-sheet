# Getting Started

## Installing Go

Use the official `.pkg` installer from [go.dev](https://go.dev/dl/).


## Visual Studio Code

Install the Go extension from the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=golang.go).

```json title=".vscode/settings.json"
{
  // Configure Go-specific editor behaviors
  "[go]": {
    "editor.tabSize": 2,                 
    "editor.insertSpaces": false,         // Keeps real tabs (crucial for gofmt)
    "editor.formatOnSave": true,          // Automatically formats your code on save
    "editor.codeActionsOnSave": {
      "source.organizeImports": "always"  // Automatically adds missing imports and removes unused ones
    }
  },

  // Enable the official Go language server (gopls)
  "go.useLanguageServer": true,

  // Configure gopls (the Go language server) behaviors
  "go.languageServerFlags": ["-remote=auto"],
  "go.toolsManagement.autoUpdate": true, // Automatically keeps your Go tools up to date

  // Enhanced testing and structural views
  "go.testFlags": ["-v"],                // Runs tests in verbose mode by default
  "gopls": {
    "ui.navigation.importShortcut": "Definition",
    "ui.diagnostic.analyses": {
      "unusedparams": true,              // Warns you about unused function parameters
      "shadow": true                     // Warns you when variables are accidentally shadowed
    }
  }
}
```


## Running Go

Create a `main.go` file:

```go
package main

import "fmt"

func main() {
  fmt.Println("Hello, World!")
}
```

- `package main`: declares the package this code belongs to. All code in Go is organized into packages.
- `main` is special: Go programs start at the `main` function in the `main` package. Without it, compilation fails.
- `import`: declare packages to use; call their functions with `package.function(...)`.
- `{}`: place opening braces on the same line as the keyword; closing braces go on a new line aligned with it.

To run your code:

```bash
go run main.go
```
