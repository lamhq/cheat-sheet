# Control flow

## `if`

```go
if command == "go east" {
  fmt.Println("You head further up the mountain.")
} else if command == "go inside" {
  fmt.Println("You enter the cave where you live out the rest of your life.")
} else if !haveTorch || !litTorch {
  fmt.Println("Nothing to see here.")
} else {
  fmt.Println("Didn't quite get that.")
}
```


## `switch`

Matches a value against multiple cases:
```go
switch x {
case 1:
    fmt.Println("One")
case 2, 3:
    fmt.Println("Two or Three")
default:
    fmt.Println("Other")
}
```

Use expressions in cases:
```go
switch {
case x < 0:
    fmt.Println("Negative")
case x == 0:
    fmt.Println("Zero")
default:
    fmt.Println("Positive")
}
```

Used with interfaces to check the dynamic type.
```go
switch v := i.(type) {
case int:
    fmt.Println("Integer:", v)
case string:
    fmt.Println("String:", v)
default:
    fmt.Println("Unknown type")
}
```

Fallthrough (forces execution to continue to the next case):
```go
switch x {
case 1:
    fmt.Println("One")
    fallthrough
case 2:
    fmt.Println("Two")
}
```


## `for`

```go
var count = 10
for count > 0 {
  fmt.Println(count)
  time.Sleep(time.Second)
  count--
}
```

```go
var degrees = 0
for {
  degrees++
  
  if degrees >= 360 {
    degrees = 0
    if rand.Intn(2) == 0 {
      break
    }
  }
}
```


## `go.mod` file

The file `go.mod` is a module file. It defines the module, its dependencies, and other metadata that's used by the Go tooling to manage those dependencies, resolve conflicts between different modules, and enforce version compatibility.

That `go.mod` file stays with your code, including in your source code repository.

To create a `go.mod` file, run the `go mod init` [command](https://go.dev/ref/mod#go-mod-init), giving it the name of the module your code will be in. For more about naming a module with a module path, see [Managing dependencies](https://go.dev/doc/modules/managing-dependencies#naming_module).


## Printing

Passing arguments:

```go
fmt.Println("My weight on the surface of Mars is", 149.0*0.3783, "lbs, and I would be", 41*365.2425/687, "years old.")
// My weight on the surface of Mars is 56.3667 lbs, and I would be 21.79758733624454 years old.
```

Insert values anywhere in the text:

```go
// My weight on the surface of Mars is 56.3667 lbs,
fmt.Printf("My weight on the surface of Mars is %v lbs,", 149.0*0.3783)

// and I would be 21 years old.
fmt.Printf(" and I would be %v years old.\n", 41*365/687)
```

Align text, a positive number pads with spaces to the left, and a negative number pads with spaces to the right:

```go
// %4v to pad a value to a width of 4 characters.
fmt.Printf("%-15v $%4v\n", "SpaceX", 94)
```
