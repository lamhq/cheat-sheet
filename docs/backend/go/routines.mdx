# Goroutines

## Introduction

A goroutine is a lightweight thread managed by the Go runtime.

Go automatically shares a few real computer threads among thousands of Goroutines to keep things fast and cheap.

To launch a new Goroutine, prefix a function call with the `go` keyword:

```go
func sayHello() {
    fmt.Println("Hello from goroutine")
}

go sayHello() // runs concurrently
```


## Goroutines vs. OS Threads

| Feature | Goroutine | OS Thread |
| --- | --- | --- |
| **Memory Footprint** | Starts tiny (approx. 2 KB), grows dynamically. | Large static size (typically 1 MB to 8 MB). |
| **Creation/Destruction** | Fast, handled cleanly by the Go runtime. | Slow, requires OS kernel context switches. |
| **Switching Overhead** | Very low (handled in user space). | Higher (requires saving/restoring CPU registers). |


## WaitGroups

Wait for a collection of Goroutines to finish executing.

```go
var wg sync.WaitGroup

for i := 1; i <= 3; i++ {
    wg.Add(1) // Increment the counter for each goroutine
    go func(id int) {
        defer wg.Done() // Decrement counter when finished
        fmt.Printf("Worker %d working...\n", id)
    }(i)
}

wg.Wait() // Blocks execution here until counter hits 0
fmt.Println("All workers finished!")
```


## Mutexes

Used to prevent race conditions when multiple Goroutines attempt to write to the same shared memory address simultaneously.

```go
var mu sync.Mutex
var counter int

go func() {
    mu.Lock()         // Acquire exclusive lock
    counter++
    mu.Unlock()       // Release lock
}()
```


## Channels

Channels allow safely sharing data and communicating states between Goroutines without manual locking.

```go
ch := make(chan string) // Create a channel

go func() {
    ch <- "Data from background" // Send data into channel
}()

msg := <-ch // Receive data from channel (blocks until data arrives)
fmt.Println(msg)
```


## Buffered Channels

Buffered channels allow sending multiple values without immediate receiving.

```go
ch := make(chan int, 2) // type int, buffer size 2
ch <- 1
ch <- 2
fmt.Println(<-ch) // 1
fmt.Println(<-ch) // 2
```


## Select Statement

`select` lets you wait on multiple channel operations.

```go
select {
case msg1 := <-emailChannel:
    fmt.Println("Got an email:", msg1)
case msg2 := <-smsChannel:
    fmt.Println("Got a text:", msg2)
case <-time.After(3 * time.Second):
    fmt.Println("Timed out waiting for both!")
}
```


## Closing Channels

Close a channel to signal no more values will be sent:

```go
ch := make(chan int)
close(ch)
```

Iterate over channel until closed:

```go
for v := range ch {
    fmt.Println(v)
}
```
