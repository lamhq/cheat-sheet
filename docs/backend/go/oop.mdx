# OOP

Object-Oriented Programming (OOP) in Go.


## Structs

Structs are like classes with fields.

```go
type Rectangle struct {
    Width, Height float64
}

func (r Rectangle) Area() float64 {
    return r.Width * r.Height
}
```


## Methods

Functions with a receiver, similar to methods in classes.

```go
type Circle struct {
    Radius float64
}

func (c Circle) Area() float64 {
    return 3.14 * c.Radius * c.Radius
}
```


## Pointer Receivers

Use pointer receivers to modify the struct or avoid copying large structs.

```go
func (c *Circle) Scale(factor float64) {
    c.Radius *= factor
}
```


## Interfaces

Interfaces define behavior. Any type that implements the methods implicitly satisfies the interface.

```go
type Shape interface {
    Area() float64
}

func printArea(s Shape) {
    fmt.Println("Area:", s.Area())
}
```


## Embedding (Composition)

Embedding allows struct reuse and mimics inheritance.

```go
type ColoredRectangle struct {
    Rectangle
    Color string
}

cr := ColoredRectangle{Rectangle{3, 4}, "red"}
fmt.Println(cr.Area()) // inherited method
```


## Polymorphism

Different types can satisfy the same interface.

```go
shapes := []Shape{
    Rectangle{3, 4},
    Circle{5},
}

for _, s := range shapes {
    fmt.Println(s.Area())
}
```


## Constructors (Factory Functions)

Go doesn’t have constructors; use functions to initialize structs.

```go
func NewCircle(r float64) *Circle {
    return &Circle{Radius: r}
}
```
