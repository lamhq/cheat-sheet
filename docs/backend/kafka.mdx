# Kafka

## Introduction

Apache Kafka is a distributed publish-subscribe messaging system and a robust queue.

It can handle a high volume of data and enables you to pass messages from one end-point to another.

Kafka is very fast and guarantees zero downtime and zero data loss.

Messages are stored for a period of time before deleted.

Messages are replicated within the cluster to prevent data loss.

![](https://dezyre.gumlet.io/images/blog/apache-kafka-architecture-/apache_kafka_architecture.webp?w=720&dpr=2.0)


## Advantages

- **Performance**. Kafka can handle a lot of data quickly (can process 100+ events / sec). It maintains stable performance even many TB of messages are stored.
- **Reliability**. Kafka is distributed, partitioned, replicated and fault tolerance.
- **Scalability**. Kafka messaging system scales easily without down time..
- **Durability**. Kafka uses Distributed commit log which means messages persists on disk as fast as possible, hence it is durable..


## Kafka APIs

| Use Case | API | Example |
|---|---|---|
| Put data from an external system into Kafka | Kafka Connect Source | Extract customer data from PostgreSQL database into Kafka |
| Produce data directly into Kafka from your application | Kafka Producer | Send GPS coordinates from trucks directly to Kafka topic |
| Transform or process data from one Kafka topic to another | Kafka Streams | Aggregate data in real-time |
| Send processed data to external systems for storage and analysis | Kafka Connect Sink | Write processed data to PostgreSQL, ElasticSearch, or Amazon S3 |
| Perform a lightweight, one-time action with data | Kafka Consumer | Send email notifications when delivery is approaching |
| Query Kafka topics using SQL syntax | KSQL DB | Run SQL queries to aggregate website traffic statistics |
| Ensure data consistency and validate schemas across pipelines | Schema Registry | Validate that all messages follow the same data type format |
