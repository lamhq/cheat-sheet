# Kafka Streams

## Introduction

Kafka Streams is an easy-to-use data processing and transformation library within Kafka.

It allows you to write real-time streaming applications without needing a separate processing cluster.

## Use Cases

- **Data Transformations:** Reshape or filter data in real-time
- **Data Enrichment:** Add additional context to streaming data
- **Fraud Detection:** Identify suspicious patterns
- **Monitoring and Alerting:** Track metrics and trigger notifications
- **Time-series Analysis:** Aggregate data over time windows
- **Bot vs. Human Detection:** Classify user actions
- **Website Traffic Analysis:** Count changes per domain

**Example Workflow:**
1. Read from a Kafka topic
2. Apply transformations (count bots, analyze websites, compute time-series stats)
3. Output results to new topics


## Key Features

**Developer-Friendly:**
- Write as a standard Java application
- Clean DSL (Domain Specific Language) for expressing transformations
- No need to set up a separate cluster or infrastructure

**Production-Ready:**
- Highly scalable and elastic
- Fault-tolerant (automatic recovery)
- Exactly-Once semantics (leverages Kafka's transactional API for Kafka-to-Kafka workflows)
- One record-at-a-time processing (no batching latency)
- Works for any application size
