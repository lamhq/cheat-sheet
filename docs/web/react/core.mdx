# Core

## Version

This document is for version `19.1` (September 2025).

## Creating a React App

### Next.js (App Router)

A Node.js framework that supports server-side rendering (SSR), and static-site generation (SSG).
   
```sh
npx create-next-app@latest
```

### Expo (for native apps)

Lets you create universal Android, iOS, and web apps with truly native UIs.

```sh
npx create-expo-app@latest
```

### Vite (SPA)

A build tool for scaffolding a client-only, single-page app (SPA).

```sh
npm create vite@latest my-app -- --template react
```
