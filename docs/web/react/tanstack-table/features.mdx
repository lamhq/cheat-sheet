# Features

## Introduction

TanStack Table uses a plugin-based architecture where you explicitly declare the features your table needs. 

This keeps bundle sizes small and ensures only the APIs relevant to your chosen features appear in your table instance.


## Built-in Features

- **Global Filtering**: Filter rows based on search values for the entire table
- **Column Filtering**: Filter rows based on search values for a column
- **Column Visibility**: Hide/show columns
- **Row Selection**: Select/deselect rows (checkboxes)
- **Row Sorting**: Sort rows by column values
- **Row Pagination**: Paginate rows
- **Faceting**: List unique values or min/max values for a column or for the entire table
- **Column Resizing**: Let users resize columns with drag handles
- **Column Ordering**: Dynamically change the order of columns
- **Column Pinning**: Pin (Freeze) columns to the left or right of the table
- **Column Sizing**: Dynamically change the size of columns
- **Column Grouping**: Group rows by one or more column values
- **Row Aggregation**: Calculate summary values for grouped, root, or custom row sets
- **Row Expanding**: Expand/collapse rows (sub-rows)
- **Row Pinning**: Pin (Freeze) rows to the top or bottom of the table
- **Cell Selection**: Select spreadsheet-style rectangular ranges of cells
- **Cell Spanning**: Merge adjacent body cells across rows or columns


## Specify Features

You declare a table's static feature set using `tableFeatures()`, importing only the specific optional features your table needs.

To use core features only:

```ts
import { tableFeatures, useTable } from '@tanstack/react-table'

const features = tableFeatures({})

function Table() {
  const table = useTable({
    features,
    columns,
    data,
  })
  // render the table...
}
```

With optional features:

```ts
import {
  columnFilteringFeature,
  rowPaginationFeature,
  rowSortingFeature,
  tableFeatures,
  useTable,
} from '@tanstack/react-table'

const features = tableFeatures({
  columnFilteringFeature,
  rowSortingFeature,
  rowPaginationFeature,
})
```


## How Features Work

Features provide state and APIs, but don't perform client-side data processing. 

You can use a feature for its state/APIs without adding a row model if your server handles the processing instead.

Example with client-side processing:

```ts
import {
  columnFilteringFeature,
  createFilteredRowModel,
  createPaginatedRowModel,
  createSortedRowModel,
  filterFn_includesString,
  rowPaginationFeature,
  rowSortingFeature,
  sortFn_alphanumeric,
  tableFeatures,
} from '@tanstack/react-table'

const features = tableFeatures({
  columnFilteringFeature,
  rowSortingFeature,
  rowPaginationFeature,
  filteredRowModel: createFilteredRowModel(), // no-need for server side processing
  sortedRowModel: createSortedRowModel(),
  paginatedRowModel: createPaginatedRowModel(),
  filterFns: { includesString: filterFn_includesString },
  sortFns: { alphanumeric: sortFn_alphanumeric },
})
```


## Stock Features

`stockFeatures` is a convenient bundle of all optional features, useful for tables that genuinely use most features:

```ts
import { stockFeatures, tableFeatures } from '@tanstack/react-table'

const features = tableFeatures({
  ...stockFeatures,
})
```
