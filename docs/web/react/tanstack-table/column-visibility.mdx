# Column Visibility

## Setup

Add the column visibility feature to enable visibility APIs:

```tsx
import {
  useTable,
  tableFeatures,
  columnVisibilityFeature,
} from '@tanstack/react-table'

const features = tableFeatures({ columnVisibilityFeature })

const table = useTable({
  features,
  columns,
  data,
})
```

## Column Visibility State

The `columnVisibility` state is a map of column IDs to boolean values. A column is hidden if its ID is present and set to `false`:

**With Atom (v9 Recommended):**

```tsx
import { useCreateAtom, useSelector } from '@tanstack/react-store'
import { type ColumnVisibilityState } from '@tanstack/react-table'

const columnVisibilityAtom = useCreateAtom<ColumnVisibilityState>({
  columnId1: true,
  columnId2: false, // hide this column by default
  columnId3: true,
})

const columnVisibility = useSelector(columnVisibilityAtom)

const table = useTable({
  features,
  columns,
  data,
  atoms: {
    columnVisibility: columnVisibilityAtom,
  },
})
```

**With State Setter (v8 Style):**

```tsx
const [columnVisibility, setColumnVisibility] = useState<ColumnVisibilityState>({
  columnId1: true,
  columnId2: false, // hide by default
  columnId3: true,
})

const table = useTable({
  features,
  columns,
  data,
  state: { columnVisibility },
  onColumnVisibilityChange: setColumnVisibility,
})
```

**Set Initial State:**

```tsx
const table = useTable({
  features,
  columns,
  data,
  initialState: {
    columnVisibility: {
      columnId1: true,
      columnId2: false, // hide by default
      columnId3: true,
    },
  },
})
```

> Do NOT provide `columnVisibility` to both `initialState` and `state` at the same time.


## Disable Hiding Columns

Prevent specific columns from being hidden:

```tsx
const columns = [
  {
    header: 'ID',
    accessorKey: 'id',
    enableHiding: false, // cannot be hidden
  },
  {
    header: 'Name',
    accessorKey: 'name', // can be hidden
  },
]
```

## Column Visibility APIs

Use these APIs to render visibility toggle UI:

- `column.getCanHide()` - Check if column can be hidden
- `column.getIsVisible()` - Check if column is currently visible
- `column.toggleVisibility(value?)` - Toggle column visibility
- `column.getToggleVisibilityHandler()` - Event handler for toggle UI

```tsx
const columnLabels: Record<string, string> = {
  firstName: 'First Name',
  lastName: 'Last Name',
}

{
  table.getAllColumns().map((column) => (
    <label key={column.id}>
      <input
        checked={column.getIsVisible()}
        disabled={!column.getCanHide()}
        onChange={column.getToggleVisibilityHandler()}
        type="checkbox"
      />
      {columnLabels[column.id] ?? column.id}
    </label>
  ))
}
```

> Use stable text labels (custom map, `column.columnDef.meta`, or `column.id`) for visibility toggles instead of rendering the header template directly, hidden columns may not have active header context.


## Render columns

Use "visible" variants of table APIs when rendering to respect column visibility:

```tsx
<table>
  <thead>
    <tr>
      {table.getVisibleLeafColumns().map((column) => (
        // Only visible columns
      ))}
    </tr>
  </thead>
  <tbody>
    {table.getRowModel().rows.map((row) => (
      <tr key={row.id}>
        {row.getVisibleCells().map((cell) => (
          // Only visible cells
        ))}
      </tr>
    ))}
  </tbody>
</table>
```

Header group APIs automatically account for visibility. Use visible variants:
- `table.getVisibleLeafColumns()` - All visible leaf columns
- `row.getVisibleCells()` - All visible cells in a row
- Other visible APIs: `getStartVisibleLeafColumns()`, `getCenterVisibleLeafColumns()`, `getEndVisibleLeafColumns()`
