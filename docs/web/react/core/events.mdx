# Event Handlers

## Introduction

Event handlers are functions that will be triggered in response to user interactions (clicking, hovering, focusing on form inputs, etc.).

## Naming event handler functions

By convention, event handlers are typically named `handle<EventName>`, such as `handleClick` or `handleMouseEnter`.

```jsx
export default function Button() {
  function handleClick() {
    alert('You clicked me!');
  }

  return (
    <button onClick={handleClick}>
      Click me
    </button>
  );
}
```


## Naming event handler props

Event handler props are usually named with the `on` prefix, such as `onClick` or `onSmash`.

```jsx
function Button({ onSmash, children }) {
  return (
    <button onClick={onSmash}>
      {children}
    </button>
  );
}
```

## Event propagation

Event handlers will also catch events from children components. 

```jsx
export default function Toolbar() {
  return (
    <div className="Toolbar" onClick={() => {
      alert('You clicked on the toolbar!');
    }}>
      <button onClick={() => alert('Playing!')}>
        Play Movie
      </button>
      <button onClick={() => alert('Uploading!')}>
        Upload Image
      </button>
    </div>
  );
}
```

- Clicking a button runs its `onClick` before the parent's `onClick`, so two alerts appear. 
- Clicking the toolbar itself triggers only the parent handler.

## Stopping propagation

Call `stopPropagation()` on the event object to stop it from reaching parent handlers.

```jsx
function Button({ onClick, children }) {
  return (
    <button onClick={e => {
      e.stopPropagation();
      onClick();
    }}>
      {children}
    </button>
  );
}
```

## Preventing default behavior

Some browser events have default behavior associated with them. 

*For example, the `submit` event on a `<form>` element will reload the page by default.*

You can call `e.preventDefault()` on the event object to stop this from happening:

```jsx
export default function Signup() {
  return (
    <form onSubmit={e => {
      e.preventDefault();
      alert('Submitting!');
    }}>
      <input />
      <button>Send</button>
    </form>
  );
}
```
