## Start dev server

To start the development server, run the dev command:

```bash
pnpm run dev
```

## Build

To generate the static site, run the build command:

```bash
pnpm run build
```

## Change file/folder structure

Follow [Navigation Sync Rules](./navigation-sync.md) whenever you change the folder structure of `docs/`.
